# RQ2 main comparison

This directory contains the BMC-Agent and FM-Agent comparison data used in
RQ2:

- `fm-agent-candidates.tsv`: all 120 FM-Agent candidates.
- `manual-review.tsv`: human review of the 43 BMC-Agent reports and the
  reviewed FM-Agent candidates.
- `confirmed-findings-by-class.tsv`: the confirmed findings grouped by the
  primary bug classes reported in the paper.

The BMC-Agent column records 43 candidates and 21 source-confirmed findings in
13 distinct functions. FM-Agent records 120 candidates and 20 confirmed
findings in 20 functions.
